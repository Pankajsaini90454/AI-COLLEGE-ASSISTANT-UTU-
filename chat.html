Enterprise RAG Pipeline Architecture
1

Document Ingestion & Chunking

PDF documents (Syllabus, Academic Calendar, Marksheets) are parsed via pdfplumber + PyPDF2 and chunked into overlapping token windows.

2

Dense Vector Embeddings

Chunkn texts are embedded with sentence-transformers/all-MiniLM-L6-v2 (384-dimensional dense vectors) running locally on startup.

3

PostgreSQL + pgvector Indexing

Vectors are stored in PostgreSQL with HNSW / Cosine Distance (<=>) indexing for sub-5ms semantic retrieval.

4

Multi-Turn Memory & Identity Engine

User corrections (e.g. "My name is Rahul", "Cloud Computing is in 3rd sem") are extracted and persisted to disk & DB, overriding outdated doc records.

5

Grounded Gemini 3.5 Generation
